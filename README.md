# The Legend of Zelda: Ocarina of Time music pack!

This is a music pack for `sm64coopdx` bringing music from the Legend Of Zelda: Ocarina of Time. It is not finished quite yet but it can be used. Also, its free to use. I dont even want to lisence this.

all ya gotta do is `git clone` this, move the files to the mods folder on coopdx, and you have it!
